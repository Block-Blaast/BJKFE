# 사용자 앱 (`apps/user`)

- **모바일 우선**입니다. 기본 클래스가 모바일이고, 넓은 화면은 `sm:`/`md:`로 덮어씁니다. 데스크톱에서 열어도 깨지지 않게 콘텐츠 폭을 제한합니다(가운데 정렬된 모바일 폭 컨테이너).
- 터치 대상은 최소 44×44px로 만듭니다. hover에만 의존하는 UI(hover로만 보이는 버튼 등)를 만들지 마세요.
- 하단 고정 UI(탭 바, CTA 버튼)는 iOS 홈 인디케이터에 가리지 않게 `env(safe-area-inset-bottom)`을 반영합니다.
- 화면 높이는 `h-screen` 대신 `h-dvh`/`min-h-dvh`를 씁니다. 모바일 브라우저 주소창 때문에 `100vh`가 실제보다 큽니다.
- 일반 사용자가 쓰는 화면이므로 첫 로딩 속도를 우선합니다. 서버 컴포넌트에서 데이터를 받고, 클라이언트 컴포넌트는 상호작용이 필요한 부분에만 씁니다.
