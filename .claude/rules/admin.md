# 어드민 (`apps/admin`)

- **데스크톱 전용**입니다. 모바일 대응은 하지 않습니다. 최소 폭(약 1280px)을 기준으로 설계합니다.
- 레이아웃은 사이드바 + 상단바 + 콘텐츠 영역을 기본으로 하고, 공통 레이아웃은 `src/app/` 최상위 레이아웃(또는 라우트 그룹 레이아웃)에서 한 번만 정의합니다.
- 목록 화면의 필터·정렬·페이지 상태는 **URL 쿼리스트링**에 둡니다. 새로고침·뒤로 가기·링크 공유 시 상태가 유지되어야 합니다. Zustand에 두지 마세요.
- 삭제·상태 변경처럼 되돌릴 수 없는 작업은 확인 단계를 거칩니다.
- 어드민 전용 API는 `packages/api`의 `admin<도메인>.ts`에 둡니다. (`api.md` 참고)
