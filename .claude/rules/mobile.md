# 앱 화면 — 폰 (`/m/*`, M-01~05)

현장의 손입니다. 작업자는 장갑을 끼고, 사장님은 이동 중에 봅니다.

- **폰 전용 레이아웃**입니다. `app/m/layout.tsx`가 가운데 정렬된 모바일 폭(`max-w-md`) 컨테이너를 줍니다. PC에서 열어도 깨지지 않지만 PC용으로 늘리지 않습니다.
- 탭이 있는 화면(채팅·내 요청·브리핑)은 `app/m/(tabs)/`에, 탭 없이 뒤로 가기가 있는 화면(의견서·승인)은 `app/m/` 바로 아래에 둡니다.
- 터치 대상은 최소 44×44px. hover에만 의존하는 UI(hover로만 보이는 버튼 등)를 만들지 마세요.
- 하단 고정 UI(탭 바, 승인 버튼)는 `pb-safe` 유틸리티로 iOS 홈 인디케이터를 피합니다(`globals.css`).
- 화면 높이는 `h-screen` 대신 `h-dvh`/`min-h-dvh`를 씁니다. 모바일 브라우저 주소창 때문에 `100vh`가 실제보다 큽니다.
- 첫 로딩 속도를 우선합니다. 서버 컴포넌트에서 데이터를 받고, 클라이언트 컴포넌트는 상호작용이 필요한 부분에만 씁니다.
- 승인처럼 결과가 큰 버튼은 한 번 더 확인하고, 처리 중에는 버튼을 막아 두 번 눌리지 않게 합니다(서버도 `Idempotency-Key`로 막습니다).
