# 디자인 시스템 · 스타일

- 스타일은 Tailwind 클래스로 씁니다. 인라인 `style={{...}}`은 런타임에 계산되는 값(드래그 위치 등)에만 씁니다.
- Tailwind v4라 `tailwind.config.*` 파일이 없습니다. 색·폰트·간격 토큰은 `src/app/globals.css`의 `@theme` 블록에 정의합니다.
- **간격·색·반경·폰트 크기에 임의값(`p-[13px]`, `text-[#FF8800]`)을 쓰지 마세요.** 기본 스케일을 쓰거나 `@theme`에 토큰을 먼저 추가합니다. 요소 크기(`w-[60px]`, `h-[...]`)는 허용됩니다. (hook이 차단)
- 조건부 클래스를 템플릿 문자열로 조각내 만들지 마세요(`` `bg-${color}-500` `` X). Tailwind가 감지하지 못합니다. 완성된 클래스명을 분기합니다.
- 버튼·입력·텍스트 같은 공용 UI는 `src/components/ui/`의 컴포넌트를 먼저 찾아 쓰고, 없으면 거기에 만듭니다.
- 반응형은 모바일 우선입니다. 기본 클래스가 모바일, `sm:`/`md:`/`lg:`로 넓은 화면을 덮어씁니다.
